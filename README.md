# Calculadora Pro Freelancer

Calculadora gratuita en español para freelancers: calcula cuánto cobrar por un proyecto sin regalar tu trabajo.

👉 **Pruébala en vivo:** https://fenix17650.github.io/calculadora-freelance/

## ¿Qué hace?

- Calcula el costo base (horas × tarifa por hora)
- Suma gastos del proyecto
- Aplica margen de ganancia e impuestos
- Agrega recargo por urgencia (normal, urgente o emergencia)
- Muestra el precio final con desglose

## ¿Para quién es?

Para diseñadores, programadores, redactores, fotógrafos, editores de video, consultores y cualquier freelancer en México y Latinoamérica que quiera poner precios profesionales.

## ¿Cómo se usa?

1. Elige tu tipo de servicio.
2. Escribe tu tarifa por hora y las horas estimadas.
3. Agrega gastos, margen de ganancia e impuestos.
4. Elige la urgencia y pulsa **Calcular Precio Profesional**.

Todo funciona en tu navegador, no necesitas registrarte.

## Tecnologías

HTML, CSS y JavaScript. Sin servidor.
